# Room Studio — โปรแกรมออกแบบห้อง 2D และ 3D

Room Studio เป็นเว็บแอปพลิเคชันสำหรับวางแผนการจัดห้อง ผู้ใช้สามารถกำหนดขนาดห้อง เลือกเฟอร์นิเจอร์และของตกแต่ง จัดวางในแปลน 2D แล้วตรวจดูผลในมุมมอง 3D ได้ เหมาะสำหรับใช้เป็นต้นแบบการออกแบบห้องและประกอบการนำเสนอโครงงานระดับปริญญาตรี

> **หมายเหตุ:** โปรแกรมนี้เป็นเครื่องมือช่วยวางแผนเบื้องต้น ขนาดและตำแหน่งในโปรแกรมไม่ใช้แทนแบบก่อสร้างหรือการวัดหน้างานจริง

## ภาพรวมโครงงาน

- **ชื่อโครงงาน:** Room Studio — โปรแกรมออกแบบห้อง 2D และ 3D
- **ประเภท:** เว็บแอปพลิเคชันแบบ Front-end
- **กลุ่มผู้ใช้เป้าหมาย:** ผู้ที่ต้องการทดลองจัดวางเฟอร์นิเจอร์และดูภาพรวมของห้อง
- **แนวคิดหลัก:** เชื่อมโยงแปลน 2D กับภาพจำลอง 3D เพื่อให้เห็นขนาดและตำแหน่งของสิ่งของได้เข้าใจง่ายขึ้น

### วัตถุประสงค์

1. ให้ผู้ใช้กำหนดขนาดและรูปแบบห้องได้ด้วยตนเอง
2. ให้เพิ่ม ย้าย หมุน ปรับขนาด และลบเฟอร์นิเจอร์ในแปลนได้
3. แสดงผลห้องและโมเดลเฟอร์นิเจอร์ในมุมมอง 3D
4. ให้บันทึกแบบไว้ในเบราว์เซอร์และส่งออกแปลนเป็นภาพ PNG

## ความสามารถของระบบ

- เลือกแม่แบบห้องนอน ห้องนั่งเล่น หรือห้องทำงาน และปรับความกว้างกับความยาวของห้องได้
- เปลี่ยนสีพื้นและผนัง เลือกรูปแบบการตกแต่ง และเปิดหรือปิดเส้นกริดได้
- ค้นหาและเลือกเฟอร์นิเจอร์ ของตกแต่ง ประตู และหน้าต่างจากแค็ตตาล็อกโมเดล 3D
- จัดวางวัตถุผ่านมุมมอง 2D หรือ 3D พร้อมปรับตำแหน่ง การหมุน และขนาดผ่านแผงคุณสมบัติ
- ย้ายวัตถุที่รองรับไปวางบนโต๊ะ หรือปรับระดับความสูงของของตกแต่งที่แขวนผนังได้
- ใช้คำสั่งย้อนกลับ บันทึกแบบ โหลดแบบ เริ่มแบบใหม่ และส่งออกแปลน 2D เป็น PNG

## เทคโนโลยีที่ใช้

- HTML, CSS และ JavaScript แบบ ES Modules
- [Three.js](https://threejs.org/) สำหรับฉาก 3D, กล้อง และการแสดงผลโมเดล GLB
- [GLTFLoader](https://threejs.org/docs/#examples/en/loaders/GLTFLoader) สำหรับโหลดโมเดล 3D
- Canvas 2D API สำหรับวาดแปลนห้องและส่งออกภาพ
- โมเดลและภาพตัวอย่างเก็บไว้ภายในโฟลเดอร์ `assets/models/`

## สิ่งที่ต้องมีก่อนเริ่มใช้งาน

- Python 3 สำหรับเปิดเว็บเซิร์ฟเวอร์ในเครื่อง (หรือเว็บเซิร์ฟเวอร์แบบ static อื่น)
- เว็บเบราว์เซอร์รุ่นปัจจุบันที่รองรับ JavaScript Modules และ WebGL เช่น Chrome หรือ Edge
- การเชื่อมต่ออินเทอร์เน็ตขณะเปิดแอป เนื่องจาก Three.js และส่วนเสริมบางรายการโหลดจาก jsDelivr CDN

โปรเจกต์นี้ไม่มีขั้นตอนติดตั้งแพ็กเกจผ่าน npm และไม่ควรเปิด `index.html` ด้วยการดับเบิลคลิก เพราะเบราว์เซอร์อาจไม่อนุญาตให้โหลด ES Modules และโมเดลจาก `file://`

## วิธีเปิดใช้งาน

เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```powershell
py -m http.server 8000
```

จากนั้นเปิดเบราว์เซอร์ไปที่:

```text
http://localhost:8000/
```

หากเครื่องไม่มีคำสั่ง `py` ให้ลองใช้ `python -m http.server 8000` แทน เมื่อต้องการหยุดเซิร์ฟเวอร์ให้กลับไปที่ Terminal แล้วกด `Ctrl+C`

## วิธีใช้งานโดยย่อ

1. เลือกแม่แบบห้อง หรือกำหนดความกว้างและความยาวเป็นเมตร
2. เลือกหมวดหมู่และค้นหาโมเดลในแค็ตตาล็อกด้านซ้าย จากนั้นคลิกเพื่อเพิ่มเข้าห้อง
3. เลือกโหมด **2D แปลน** เพื่อคลิกเลือกและลากย้ายวัตถุ หรือเลือกโหมด **3D มุมมอง** เพื่อดูและจัดวางในฉาก
4. เมื่อเลือกวัตถุแล้ว ใช้แผงคุณสมบัติด้านขวาเพื่อแก้ชื่อ ขนาด ตำแหน่ง ความสูง หรือหมุนทีละ 15 องศา
5. กด **บันทึกแบบ** เพื่อเก็บแบบไว้ในเบราว์เซอร์นี้ หรือ **ส่งออก PNG** เพื่อดาวน์โหลดภาพแปลน 2D

การบันทึกใช้ `localStorage` ของเบราว์เซอร์ จึงไม่ใช่การบันทึกขึ้นระบบออนไลน์ และข้อมูลจะผูกกับเบราว์เซอร์และที่อยู่เว็บที่ใช้เปิดแอป

## โครงสร้างไฟล์สำคัญ

```text
├── index.html                 โครงสร้างหน้าเว็บและจุดโหลด JavaScript
├── app.js                     การทำงานของแปลน 2D ฉาก 3D และการโต้ตอบ
├── style.css                  รูปแบบและการจัดวางส่วนติดต่อผู้ใช้
├── assets/
│   ├── models/catalog.js      รายการโมเดล ชื่อ หมวดหมู่ และขนาดตั้งต้น
│   ├── models/CREDITS.md      แหล่งที่มาและสัญญาอนุญาตของโมเดล
│   ├── models/*/*.glb         โมเดลเฟอร์นิเจอร์และของตกแต่ง
│   ├── models/previews/       ภาพตัวอย่างสำหรับแค็ตตาล็อก
│   └── picture/
├── import_model/
└── plugins/                   สคริปต์และไฟล์เครื่องมือประกอบโปรเจกต์
```

## การเพิ่มหรือแก้ไขโมเดล

รายการแค็ตตาล็อกอยู่ใน `assets/models/catalog.js` แต่ละรายการกำหนดชื่อภาษาไทย หมวดหมู่ ประเภท ขนาดเริ่มต้น และพาธของไฟล์โมเดล หากเพิ่มโมเดลใหม่ ให้เก็บไฟล์ GLB ไว้ในหมวดย่อยที่เหมาะสมและเพิ่มข้อมูลรายการในไฟล์แค็ตตาล็อก

บันทึกแหล่งที่มา ผู้สร้าง และสัญญาอนุญาตของโมเดลหรือภาพที่นำเข้าทุกชิ้นใน [`assets/models/CREDITS.md`](assets/models/CREDITS.md) ก่อนเผยแพร่ผลงาน

## ขอบเขตและข้อจำกัด

- ระบบทำงานฝั่งเบราว์เซอร์ ไม่มีบัญชีผู้ใช้ ฐานข้อมูล หรือการซิงก์แบบข้ามอุปกรณ์
- การบันทึกแบบเก็บข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์ปัจจุบัน
- ต้องใช้อินเทอร์เน็ตเพื่อโหลดไลบรารี Three.js จาก CDN; ไฟล์โมเดลในแค็ตตาล็อกเก็บอยู่ในโปรเจกต์
- ขนาดโมเดลและความแม่นยำของตำแหน่งขึ้นกับข้อมูลที่กำหนดในแค็ตตาล็อกและไฟล์ต้นฉบับ ควรตรวจสอบกับขนาดจริงก่อนนำไปใช้งาน
- การส่งออก PNG เป็นภาพแปลน 2D ไม่ใช่ภาพเรนเดอร์ 3D

## การทดสอบและตรวจสอบงาน

ก่อนสาธิตหรือส่งมอบ ควรเปิดเว็บผ่านเซิร์ฟเวอร์ในเครื่องและตรวจสอบกรณีต่อไปนี้ด้วยตนเอง:

1. เปลี่ยนแม่แบบและขนาดห้อง แล้วตรวจดูพื้นที่และกริด
2. เพิ่ม ย้าย หมุน ปรับขนาด และลบวัตถุในแปลน
3. สลับระหว่างมุมมอง 2D และ 3D และตรวจว่าโมเดลโหลดครบ
4. บันทึกและโหลดแบบจากเบราว์เซอร์เดิม
5. ส่งออก PNG และเปิดไฟล์ที่ได้
